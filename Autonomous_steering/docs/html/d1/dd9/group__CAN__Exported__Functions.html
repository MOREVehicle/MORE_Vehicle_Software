Transmits a CAN FD message using the specified FDCAN peripheral.

Parameters

dataPointer to the data buffer to be transmitted (up to 32 bytes).
device_on_canStandard ID (11-bit) of the target CAN device.
Return values
None
Note
Configures and sends a 32-byte CAN FD frame. Calls Error_Handler on failure.
Parameters
hfdcanPointer to the FDCAN handle (e.g., &hfdcan1 or &hfdcan2).
dataPointer to the data buffer to be transmitted (up to 32 bytes based on configured DLC).
device_on_canStandard ID (11-bit) of the target CAN device.
Return values
None
Note
This function configures the FDCAN_TxHeaderTypeDef with standard settings for CAN FD, including 32-byte data length, bit rate switching, and FD frame format. It adds the message to the transmission FIFO queue. The CAN_error() function is called if transmission fails.

void LWS_Send_Calibration_Command ( uint8_t ccw_value)

Performs a full calibration sequence for the LWS sensor.

This function first sends a reset calibration command and then initiates a new calibration. Delays are inserted to allow the sensor time to process each step.

Performs a full calibration sequence for the LWS sensor.

This function sends a command to the sensor via CAN to perform calibration-related actions. The command is encoded in the first byte with only the lower 3 bits used.

Parameters
ccw_valueThe calibration command word (only bits 0–2 are used).
