\doxysubsection{Detailed Description}
main loop of the steering box 

The main file initialises the modules and then loops wait for an event to occur. 1\+: The angle sensor send data to CAN 2 2\+: The car\textquotesingle{}s main can bus has send data to CAN 1 3\+: event 1 hasn\textquotesingle{}t occured for X amount of time

Event 1 means data is ready so it gathers all other data and sends it over CAN 1 to the rest of the car. Event 2 means that a command has been send from the car\textquotesingle{}s CAN bus, once this happens this command is processed. Event 3 means that the angle sensor is unresponsive, so it sends a error message (and shut the system down???)
